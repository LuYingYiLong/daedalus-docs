Configure Studio
================

Open the separate Settings window to configure providers, defaults,
integrations, appearance, and data-related preferences.

.. toctree::
   :maxdepth: 2

   providers
   integrations
   workspace-tools
   preferences
   maintenance

Settings are grouped by user task. You do not need to configure every page;
start with **Provider**, **Default model**, and **Godot Projects** for a basic
Godot workflow.
