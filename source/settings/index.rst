Configure Studio
================

Open the separate Settings window to configure models, Studio preferences,
extensions, development environments, worktrees, and local resources.

Settings are grouped by user task. You do not need to configure every page;
start with **Provider**, **Default model**, **Development environments**, and
**Godot Projects** for a basic Godot workflow.

Settings groups
---------------

The Settings window uses five groups:

* **Models** — **Provider** and **Default model**;
* **Studio** — **General**, **Appearance**, **Keyboard shortcuts**, **Search**,
  **Statistics**, and **Personalization**;
* **Extensions** — **MCP Servers**, **Skills**, **Hooks**, and **Plugins**;
* **Workspace** — **Browser**, **Development environments**, **Worktrees**,
  and **Godot Projects**;
* **Resources** — **Documentation**, **Archived sessions**, **Import**, and
  **About**.

The group determines where a page appears in the Settings navigation. For
example, theme controls belong to **Appearance**, while the global Godot
executable belongs to **Development environments**.
