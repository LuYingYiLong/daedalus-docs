Keyboard Shortcuts
==================

The bindings below are the default bindings on Windows and Linux. ``Mod``
means ``Ctrl`` on Windows and Linux, and ``Cmd`` on macOS if you run a
compatible build. You can change them from **Settings > Keyboard shortcuts**.

.. list-table::
   :header-rows: 1
   :widths: 42 28 30

   * - Action
     - Default binding
     - Purpose
   * - Toggle workspace sidebar
     - ``Ctrl+B``
     - Show or hide the workspace tree.
   * - Toggle bottom panel
     - ``Ctrl+J``
     - Show or hide terminal and other bottom panels.
   * - Toggle session sidebar
     - ``Ctrl+Alt+B``
     - Show or hide the session-side panel.
   * - New session
     - ``Ctrl+N``
     - Create a session in the current workspace.
   * - Previous session
     - ``Ctrl+PageUp``
     - Move to the previous session.
   * - Next session
     - ``Ctrl+PageDown``
     - Move to the next session.
   * - Previous conversation turn
     - ``PageUp``
     - Move to the previous turn.
   * - Next conversation turn
     - ``PageDown``
     - Move to the next turn.
   * - Find in conversation
     - ``Ctrl+F``
     - Search the current conversation.
   * - Stop computer control
     - ``Ctrl+Alt+Esc``
     - Immediately stop active computer control. This safety shortcut is not
       configurable.

Changing a binding
------------------

#. Open **Settings > Keyboard shortcuts**.
#. Search for the action.
#. Select the action and press the new shortcut.
#. Save the change.

Printable keys cannot be used by themselves, and Studio rejects a shortcut
that conflicts with another configured action. If a shortcut does not work,
check whether a text field or the operating system is currently consuming the
same key combination.
