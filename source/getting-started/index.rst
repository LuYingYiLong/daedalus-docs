The shortest path
-----------------

#. Install Studio on Windows.
#. Complete the first-run setup, or skip optional steps and return to them in
   Settings.
#. Add a workspace for your project.
#. Create a session, choose a model, and describe one concrete task.
#. Review the proposed changes and verification output.

You do not need to configure every integration before asking a question. A
provider is the only essential integration for an AI conversation; Godot and
offline documentation become important when you want Godot-aware work.
