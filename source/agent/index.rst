Use the Daedalus Agent
======================

Studio gives the agent a controlled path from a request to a reviewable
project result.

.. toctree::
   :maxdepth: 2

   modes
   composer
   timeline

The agent can answer directly, inspect a project, propose a plan, edit files,
run verification, and report evidence. It is not a replacement for your code
review: use the timeline and Git diff to decide whether the result is correct.
