Workspaces and Sessions
=======================

Workspaces define where Studio is allowed to work. Sessions keep the work
organized inside those boundaries.

.. toctree::
   :maxdepth: 2

   projects
   sessions
   context
   workbench

Choose a workspace for the task you are doing. If you have several Godot
projects, keep them as separate workspaces so file paths, Git changes, and
Godot context stay easy to understand.
