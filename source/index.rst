Daedalus Studio User Guide
==========================

Daedalus Studio is a Windows desktop workbench for building Godot projects
with an AI agent. It keeps the conversation, project context, tool activity,
approvals, file changes, and verification results together so that you can
review what happened before you keep the change.

This guide is written for people using Studio, not for contributors
maintaining its source code. Start with :doc:`getting-started/index` if you
have not installed Studio yet. If you are already working in a project, go to
:doc:`workspaces/index` or :doc:`agent/index`.

.. note::

   Daedalus Studio, Daedalus Backend, and the Godot Daedalus editor plugin are
   released as a coordinated set. Studio normally manages the backend and
   plugin versions for you. Do not mix components from unrelated releases
   unless you are deliberately testing an integration.
